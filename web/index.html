02 / api

        
API reference

        
The generator above is just a client for this API: it calls GET /qr directly, with no separate backend logic.

      


      

        

          

            GET/qr
            live
          

          
The primary endpoint. Cache-friendly and meant to be used directly as an <img src> target. Returns raw image bytes with Cache-Control: public, max-age=31536000, immutable.

          
If data exceeds capacity for the chosen ecl, it fails with 400 and a clear message.

        


        

          

            POST/qr
            live
          

          
Escape hatch for long payloads. Same fields as the GET params, as a JSON body. Response is the raw image bytes (not JSON/base64).

          
Not cache-controlled. Body limit 64 KiB.

        


        

          

            GET/healthz
            live
          

          
Returns 200 ok. Used by the Docker healthcheck, and by the status pill in the nav.

03 / about

        
About

      


      

        

          

            QR Studio is an API for turning any URL, string, or blob of text into a QR code — for embedding
            in an app, printing on packaging or signage, or generating one-off codes from a script or CI
            pipeline. Point an <img> tag, a backend job, or a build step at
            GET /qr and get back an image; every option above — colors, shape, error correction — is just part of that same request. Output is fully deterministic per parameter set, so
            GET /qr responses are cached for a year at the edge.
